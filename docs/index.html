ADSearch

RSAT 不要で Active Directory を調べる PowerShell ライブラリ

English

どんなもの？

RSAT（リモートサーバー管理ツール）をインストールできない端末でも、一般のドメインユーザーのまま Active Directory・DNS・グループポリシー・Exchange の情報を取得できる PowerShell モジュールです。

  • 書き方は RSAT とほぼ同じ：Get-ADUser・Get-ADGroupMember・Get-ADComputer などを同じ名前・同じパラメーターで使えます
  • すべて読み取り専用：公開しているコマンドは取得・検索・自己診断だけで、AD を書き換えません
  • インストール不要：ファイル共有に置いて Import-Module するだけ
  • 無料・MIT ライセンス。PowerShell 5.1 以上
ダウンロード（ZIP） リファレンスマニュアル

PowerShell で ADSI を使って AD を読む

手で書く ADSI のコードとの違い

RSAT が無い端末で PowerShell から AD を読むには、ふつうは [adsisearcher] や System.DirectoryServices.DirectorySearcher のコードを手で書きます。ADSearch はそれを RSAT と同じ形のコマンドにまとめたもので、使うのは .NET の System.DirectoryServices（ADSI/LDAP）だけです。

手で書くコードでは、LDAP フィルターを組む、取得する属性を並べる、FileTime の値と userAccountControl のビットを変換する、ページングと大きなグループを扱う、が要ります。

  • -Filter は PowerShell 形式の式（-like・-eq・かっこ・-and/-or）を受け付けて LDAP フィルターに変えます。生の LDAP フィルターはそのまま渡ります
  • 日時は日時の型で返り、LockedOut と PasswordExpired は DC が計算する属性から読みます
  • Get-ADGroupMember -Recursive は、入れ子と循環参照のグループ、メンバーが 1,500 を超えるグループ、primaryGroupID によるメンバー（Domain Users など）を扱います
  • SID と ObjectGUID は RSAT と同じ .NET の型で返ります

入手と読み込み

  1. 上のボタンで ZIP をダウンロードして展開し、ADSearch フォルダごと手元かファイル共有に置きます
  2. PowerShell で読み込みます
Import-Module C:\tools\ADSearch\ADSearch.psd1

読み込めないときとよくある質問は使い方ページに、コマンドの一覧と使用例はリファレンスマニュアルにあります。

ファイル共有と実行ポリシー

ファイル共有から読み込むとき:

Import-Module \\fileserver\tools\ADSearch\ADSearch.psd1 -Force

実行ポリシー（RemoteSigned など）で読み込めないときは、同梱の Import-ADSearch.ps1 を使います。

. ([scriptblock]::Create((Get-Content 'C:\tools\ADSearch\Import-ADSearch.ps1' -Raw)))
Import-ADSearch -Path 'C:\tools\ADSearch'

ダウンロードしたファイルは、先に Get-ChildItem -Recurse | Unblock-File でブロックを外すと、ふつうに読み込めます。

使用例とコマンド（44）

例 
# ユーザーを取得
Get-ADUser -Identity yamada -Server dc01.corp.local

# グループのメンバーを再帰的に
Get-ADGroupMember -Identity "IT-Staff" -Recursive -Server dc01.corp.local
# フィルター
Get-ADUser -Filter "DisplayName -like '山田*'" -Server dc01.corp.local

# 有効なアカウントのうちロックアウトされているもの
Get-ADUser -Filter "Enabled -eq '$true'" -Server dc01 | Where-Object LockedOut

# DNS レコード（IP アドレスつき）
Get-ADDnsRecord -Name pc001 -ComputerName dc01.corp.local

# 自己診断: 正しく読み込めたか、DC に届くか
Invoke-ADSearchSelfTest -Server dc01.corp.local

例のドメイン名とユーザー名は架空のものです。
